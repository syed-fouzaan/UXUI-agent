# AZIA Figma & FigJam Plugin User Guide

## 1. Quick Setup (Complete Beginner Guide)

You do **not** need any advanced programming or server experience to run AZIA in Figma.

### Step 1: Open Figma Desktop App
1. Open Figma and navigate to any Figma design file or FigJam board.
2. Click the **Figma Menu** (top-left dropdown) -> **Plugins** -> **Development** -> **Import plugin from manifest...**.

### Step 2: Select Manifest
1. In the file explorer, navigate to this directory:
   `D:\PROJECTS-GITHUB\UXUI Agent\azia\plugin`
2. Select `manifest.json` and click **Open**.
3. AZIA is now installed in your development plugins list!

### Step 3: Run AZIA
1. Right-click anywhere on the Figma canvas -> **Plugins** -> **Development** -> **AZIA • AI UX Copilot & Autonomous Design MCP**.
2. The interactive AZIA panel will appear on your screen.

---

## 2. Using the Plugin

### Tab 1: 🚀 Autonomous Product Design
- Enter your natural language prompt (e.g. *"Build a modern food delivery app for college students"*).
- Select your platform form factor (`Mobile` or `Desktop Web`).
- Click **✨ Generate Complete Product**.
- AZIA automatically constructs the complete design on your canvas, complete with Auto Layout, sections, sticky notes, and prototype transitions.

### Tab 2: 🔍 Nielsen UX Audit
- Select any frame, card, or screen on your Figma canvas.
- Click **🔎 Audit Selected Screen / Layer**.
- AZIA inspects the layer structure, font sizes, contrast ratios, and evaluates against Jakob Nielsen's 10 Usability Heuristics.
- Click **+ Add Canvas Annotation** to automatically pin an inline recommendation sticky next to the selected frame.

### Tab 3: 💬 Socratic Sparring
- Chat directly with AZIA's balanced critic.
- Try asking:
  - *"Challenge the assumption that users want this on the dashboard"*
  - *"Can we simplify this flow to 3 steps?"*
  - *"Show me an alternative flow"*
- AZIA responds with UX principles, trade-off analyses, and proposed layout adjustments.

---

## 3. Non-Destructive Safety Guarantee
- Every node generated by AZIA is tagged with `managed_by: "autonomous-design-mcp"`.
- AZIA will **never** silently overwrite or delete your manual Figma layers.
- If you ever want to remove an AI generation, use the **Rollback** tool to cleanly erase only the AI-created layers while preserving all your own work.
